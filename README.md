# Luma Mood Tracking App

## Overview
Luma is a mood tracking application designed to help users monitor and analyze their emotional patterns over time. The application provides a user-friendly interface for logging daily moods and reflections, offering insights that can lead to improved mental health and wellness.

## Features
- **Mood Logging**: Users can easily log their mood at any given time, selecting from a range of emotions.
- **Mood Analysis**: Visual representations of mood trends over days, weeks, or months, allowing users to identify triggers and patterns.
- **Reflection Journals**: Option for users to write reflections and notes alongside their mood entries.
- **Reminders**: The app can send push notifications to remind users to log their moods.
- **Data Export**: Users can export their mood data for further analysis.

## Installation
1. Clone the repository using:
   ```bash
   git clone https://github.com/aamisou/luma.git
   ```
2. Navigate to the project directory:
   ```bash
   cd luma
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Start the application:
   ```bash
   npm start
   ```

## Usage
- After starting the app, create an account or log in.
- Begin logging your mood by selecting an emoji or mood descriptor.
- Add reflective notes to your entries to enhance your emotional tracking.
